# Contributing

External contributions are not accepted unless a separate prior written contribution agreement is in place.

Issue reports may be used as engineering input, but submission does not create acceptance, confidentiality, compensation, licensing, approval, or implementation obligations.

## Line Endings

Repository text files shall use canonical LF as enforced by `.gitattributes`. Before committing, confirm `git diff --check` and `python tools/validate_project_repository.py` pass. Do not commit bulk CRLF conversion or tool-generated line-ending churn.
